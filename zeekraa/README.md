# نظام الدعوات الرقمية (PHP + MySQL)

دعوات زفاف رقمية بالعربي (RTL): كل دعوة لينك واحد فيه عد تنازلي، مناسبات متعددة (كتب كتاب / حنة / فرح)،
خريطة، إضافة للتقويم (.ics)، موسيقى، معرض صور، RSVP، ولينك خاص باسم كل ضيف (مع زرار واتساب جاهز).

## التثبيت السريع (Hostinger أو أي استضافة PHP)
1. من لوحة الاستضافة اعمل **قاعدة MySQL** (اسم + مستخدم + كلمة سر).
2. ارفع محتوى الفولدر (أو `zeekraa.zip` من `./build-zip.sh`) في `public_html` وفك الضغط.
3. افتح `https://موقعك/install/` ← املا بيانات MySQL + إيميل وكلمة سر الأدمن ← **ثبّت**.
4. سجّل دخول من `/admin/` وابدأ بـ **+ دعوة جديدة**.
5. بعد التثبيت امسح فولدر `install/` للأمان.

المتطلبات: PHP 8.0+، `pdo_mysql`، `mbstring`، `fileinfo`، Apache (`.htaccess` / mod_rewrite).
على Hostinger استخدم السيرفر `127.0.0.1` أو `localhost` في خانة السيرفر.

## لوحة العروسين (لكل عميل لوحته)
من `/admin/` ← تعديل الدعوة ← قسم **لوحة العميل**: اكتب إيميل العروسين وولّد كلمة سر وابعتهم لهم.
العروسين يدخلوا من `/panel/` ويشوفوا: عدد المدعوين والحاضرين والمعتذرين ولسه ماردّوش ونسبة الرد، وقائمة الردود (بحث + فلتر + رسائل التهنئة)،
وإدارة المدعوين (لينك خاص لكل ضيف + زرار واتساب/تذكير) وتحميل CSV. اللوحة بتلبس نفس لون الدعوة.
لو بتحدّث نسخة قديمة: أول فتح لصفحة دخول الأدمن أو العميل بيضيف الأعمدة الجديدة تلقائيًا.

## الأقسام
- `/admin/` لوحة التحكم: الدعوات، الضيوف (إضافة بالجملة: `الاسم | الموبايل | العدد`)، الردود + تصدير CSV.
- `/اسم-الدعوة` الصفحة العامة. `?g=TOKEN` بيعرض اسم الضيف ويحدد أقصى عدد أفراد.
- 8 تصميمات: royal / emerald / minimal / rose / navy / lavender / sage / burgundy، وكمان **لون مخصص** لكل دعوة (متغيرات CSS في `assets/invite.css`، ولإضافة تصميم جديد ضيف سطر `.t-name{...}` وسجّله في `lib/themes.php`).
- صورة الغلاف بتظهر كاملة والكتابة تحت منها؛ والمعرض بيفتح بحجم كبير مع تنقل بالأسهم والسحب.

## الأمان
كلمات السر بـ `password_hash`، استعلامات PDO محضّرة، CSRF على كل الفورمات، رفع الصور بفحص النوع الفعلي
ومنع تنفيذ PHP في `uploads/`، الدعوات `noindex`، وخيار كلمة سر لكل دعوة.

## ملاحظات
- الموسيقى: حط رابط mp3 بترخيص مناسب (الأغاني التجارية محمية بحقوق الملكية).
- بيانات الضيوف شخصية: احذف الدعوات القديمة بعد المناسبة (حذف الدعوة بيحذف ضيوفها وردودها).
